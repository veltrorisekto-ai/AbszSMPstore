? Soalan Lazim (FAQ)

Adakah game ini percuma?⌄

Build Online Alpha rasmi ini tersedia untuk dimuat turun. Game masih dalam pembangunan dan mungkin mempunyai pepijat.

Bolehkah saya main di Android dan PC?⌄

Ya. Android dan Windows menggunakan server multiplayer yang sama. Sesi tetamu pada setiap peranti berasingan; cross-save belum tersedia.

Adakah progres saya akan disimpan?⌄

Game mempunyai sistem progres berasaskan server, tetapi alpha mungkin berubah. Jangan anggap sesi tetamu boleh dipindah antara peranti.

Kenapa Windows Defender beri amaran?⌄

Launcher alpha belum mempunyai sijil Authenticode. Muat turun hanya daripada laman rasmi, semak SHA-256, dan jangan matikan perlindungan antivirus.

Bagaimana jika download gagal?⌄

Cuba semula menggunakan sambungan yang stabil dan pastikan ruang peranti mencukupi. Jika masih gagal, laporkan di Discord bersama peranti dan mesej ralat.

Adakah setiap kemas kini memerlukan APK/ZIP baharu?⌄

Kandungan yang serasi boleh dimuat turun dalam game. Kemas kini launcher, enjin atau komponen native masih memerlukan pemasang baharu.
