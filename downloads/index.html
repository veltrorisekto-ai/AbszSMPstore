04 / BEFORE YOU ENTER

Panduan
pengembara.

Bagaimana memasang pada Android?+

Muat turun APK rasmi di atas. Buka fail itu dan benarkan pemasangan daripada pelayar atau pengurus fail anda apabila Android meminta. Pasang, kemudian buka game dalam mod landskap. Sambungan internet diperlukan untuk memuat turun kandungan dan memasuki realm.

Untuk update, pasang APK baharu di atas aplikasi lama. Jangan uninstall jika anda mahu mengekalkan token sesi tetamu pada telefon itu.

Bagaimana bermain pada PC?+

Muat turun ZIP Windows, pilih Extract All dan buka Absz-Dungeon-GO.exe. Benarkan launcher memuat turun kandungan. WASD untuk bergerak, Space untuk serang, E untuk Sunfall, Q untuk Aegis, B untuk recall dan Enter untuk chat.

Launcher alpha ini belum mempunyai sijil Authenticode. Jika Windows memaparkan amaran penerbit, semak SHA-256 dengan halaman rasmi sebelum membuat keputusan untuk menjalankannya. Kekalkan perlindungan antivirus anda.

Bolehkah pemain Android dan PC berjumpa?+

Ya, kedua-dua platform menggunakan server game yang sama. Pemain mesti berada dalam realm yang sama untuk melihat dan berbual sesama sendiri. Realm lain boleh diwujudkan apabila had 24 pemain dicapai.

Akaun tetamu pada telefon dan PC ialah sesi berasingan. Pemindahan akaun atau cross-save antara peranti belum tersedia.

Adakah APK baharu diperlukan untuk setiap update?+

Fail kandungan yang serasi boleh dimuat turun terus oleh launcher. Perubahan pada launcher, enjin, keizinan Android atau ciri native memerlukan APK atau launcher PC baharu.

Apakah perlindungan yang ada?+

Build ini menyemak tandatangan manifest rasmi, hash pemasang / launcher dan kandungan game sebelum memuatkan dunia. Data progres dan keputusan gameplay penting disahkan oleh server.

Semakan ini membantu mengesan perubahan, tetapi tidak boleh menghalang semua decompile, extract atau reverse engineering pada peranti pengguna. Extract ZIP PC ialah langkah pemasangan biasa.
